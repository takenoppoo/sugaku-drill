数学ドリル

「初めて解く人でも、こう解くんだ」と思える数学の問題集。例題の手順を1つずつ追えば、同じ手順で練習問題が解けます。

第1章　因数分解

例題 1因数分解① たすき掛け（基本）因数分解のたすき掛けを、例題1つで手順どおりに解き方から解説。練習問題と解答つき。例題 2因数分解② たすき掛け（文字が2つ）xとyの2文字のたすき掛けによる因数分解を、手順どおりに解説。練習問題と解答つき。例題 3因数分解③ 置き換え同じかたまりを文字でおく「置き換え」の因数分解を、例題1つで手順どおりに解説。練習問題と解答つき。例題 4因数分解④ 置き換え（かけ算の組み合わせ）4つの積の形の式を、足して同じになる組でかけ算して置き換える因数分解を解説。練習問題と解答つき。

このサイトの使い方

  1. 例題の「解き方」を読んで、考え方をつかむ。
  2. 「解答」のSTEPを1つずつ追う。
  3. 練習問題を解く。練習問題は、例題と同じ手順で解けるものだけです。
  4. 解答は別冊ページで確認する。
